# Matriz de evidências — feature 001-complete-ios-game

Estado em 17/10/2026. Esta matriz distingue testes autorais no Windows de execução do jogo e de medições no iPhone físico. Fonte dos critérios: `../../specs/001-complete-ios-game/spec.md` no WorkspaceRoot. Os marcadores T001–T032, T035–T036, T040–T042, T044–T045, T052–T145 indicam implementação e testes rigorosos no host, sem falsa aceitação de gameplay em hardware físico. Nenhum marco S8/S9 foi demonstrado sem o aparelho físico.

## Protocolo de reprodução deste ciclo

- Ambiente: Windows 10, MinGW-w64 via `../.tools/w64devkit/bin`, CMake/CTest; branch `auto/ios-game`.
- Procedimento no RepoRoot: `PATH="$(pwd)/../.tools/w64devkit/bin:$PATH" cmake --build build-Release --parallel 4` e `PATH="$(pwd)/../.tools/w64devkit/bin:$PATH" ctest --test-dir build-Release --output-on-failure --timeout 20`.
- Esperado: compilação de release e 64 testes host aprovados. Obtido: build concluído; 64/64 testes aprovados (100% passed) em ~8,5 s.
- Governança de publicação: `tools/check-source.ps1 -SelfTest` e `tools/check-source.ps1` aprovados sem violações de política em 308 arquivos rastreados.
- Limites: testes de host usam fixtures e simulações de hardware; validação em hardware físico iPhone 15 Pro requer sideloading via Sideloadly/AltStore com dump comercial. Não publicar logs brutos nem anexar binários restritos.
